# Non-Technical Explanations

Load the full analogies reference when you need to explain a technical choice to a non-technical user:

`get_skill_reference("non-technical-explanations", "analogies.md")`

## When to Use This Skill
- The user asks "what does X mean?" about a technical concept
- You're presenting options and the user seems unsure
- You need to explain a tradeoff and the user may not know the jargon

## Rule
Always explain in terms anyone can understand. Use analogies. If in doubt, load the reference — don't assume the user knows the technical details.
